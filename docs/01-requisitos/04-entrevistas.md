# Guía y registro de entrevistas

## Guía sugerida

1. ¿Qué tarea necesita realizar y qué dificultad encuentra actualmente?
2. ¿Qué acciones debe ejecutar la plataforma y cuáles deben impedirse?
3. ¿Cómo espera iniciar, confirmar, cancelar y detener una orden?
4. ¿En qué condiciones de distancia, iluminación, postura y duración se usará?
5. ¿Qué debería suceder si se pierde la mirada, la comunicación o la alimentación?
6. ¿Qué tiempo de respuesta y tasa de acierto serían aceptables, y cómo se medirían?
7. ¿Qué información necesita ver el usuario durante el control?
8. ¿Qué limitaciones de equipo, presupuesto, acceso o calendario existen?
9. ¿Qué datos pueden registrarse y con qué autorizaciones?
10. ¿Qué demostración o prueba permitiría aceptar el resultado?
