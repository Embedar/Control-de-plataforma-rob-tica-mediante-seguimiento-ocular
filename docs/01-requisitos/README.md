# Levantamiento de requisitos

**Estado:** borrador inicial; sin requisitos aprobados.

Esta etapa busca entender el problema, acordar el alcance y especificar comportamientos verificables antes de decidir la solución técnica.

## Documentos y orden de trabajo

1. [Contexto y alcance](01-contexto-y-alcance.md).
2. [Interesados](02-interesados.md).
3. [Plan de levantamiento](03-plan-de-levantamiento.md).
4. [Guía y registro de entrevistas](04-entrevistas.md).
5. [Catálogo de requisitos](05-catalogo-de-requisitos.md).
6. [Casos de uso](06-casos-de-uso.md).
7. [Matriz de trazabilidad](07-matriz-de-trazabilidad.md).
8. [Revisión y aprobación](08-revision-y-aprobacion.md).

## Criterio de cierre de la etapa

Alcance acordado, fuentes identificadas, requisitos claros y medibles, casos principales descritos, riesgos y pendientes resueltos o aceptados explícitamente, trazabilidad a pruebas previstas y aprobación registrada por los responsables definidos.

Los ejemplos y preguntas de estas plantillas no reemplazan entrevistas ni evidencias. No se presupone una cámara, algoritmo, plataforma, población o protocolo de comunicación específicos.
