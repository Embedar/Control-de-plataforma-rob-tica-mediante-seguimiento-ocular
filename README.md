# Control de una plataforma robótica mediante seguimiento ocular

Repositorio del proyecto de grado: documentación, diseño, implementación y evidencias de validación del control de una plataforma robótica mediante seguimiento ocular (*eye tracking*).

## Estado actual

**Etapa:** preparación del levantamiento de requisitos. La estructura está disponible; los documentos son borradores y no constituyen una especificación aprobada.

## Por dónde empezar

1. Completar el [contexto y alcance](docs/01-requisitos/01-contexto-y-alcance.md).
2. Identificar los [interesados](docs/01-requisitos/02-interesados.md) y acordar el [plan de levantamiento](docs/01-requisitos/03-plan-de-levantamiento.md).
3. Registrar las entrevistas y convertir los hallazgos en requisitos verificables.
4. Revisar el [catálogo de requisitos](docs/01-requisitos/05-catalogo-de-requisitos.md), los casos de uso y la trazabilidad con los responsables.

## Cómo trabajar

Editar los documentos en Markdown, registrar las fuentes y conservar los identificadores de requisitos. Documentar los cambios y decisiones relevantes. Las aprobaciones deben registrar responsable y fecha.

No agregar credenciales, información personal de participantes ni grabaciones sin autorización. Las carpetas existentes fuera de este repositorio no se incorporaron automáticamente.
