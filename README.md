# Control de plataforma robótica mediante seguimiento ocular

Proyecto de grado de Lorenzo Martínez Sandoval, Ingeniería Electrónica, Universidad Santo Tomás.

El sistema permitirá seleccionar y confirmar un destino con la mirada para que una plataforma móvil transporte un objeto previamente cargado y realice una entrega simple en un entorno interior controlado.

## Documentación actual

**[Levantamiento de requisitos](docs/levantamiento-de-requisitos.md)**
